# Модуль учета расходов для InvoicePlane

Модуль для управления расходами в системе InvoicePlane, аналогичный существующему модулю счетов.

## Описание

Модуль учета расходов добавляет в InvoicePlane функциональность для:
- Создания и управления расходами
- Категоризации расходов (канцелярские товары, транспорт, питание, IT, маркетинг и др.)
- Отслеживания статусов (новый, подтвержденный, оплаченный)
- Автоматического расчета сумм и налогов
- Генерации отчетов по расходам
- Интеграции с существующей системой налогов и валют

## Установка

### 1. Копирование файлов
Скопируйте папку `expenses_module` в директорию `/application/modules/` вашей установки InvoicePlane.

### 2. Создание таблиц базы данных
Выполните SQL скрипт `sql/create_tables.sql` в вашей базе данных. Это создаст все необходимые таблицы:
- `ip_expense_categories` - категории расходов
- `ip_expenses` - основная таблица расходов
- `ip_expense_amounts` - суммы расходов
- `ip_expense_items` - позиции расходов
- `ip_expense_item_amounts` - суммы позиций
- `ip_expense_tax_rates` - налоги по расходам
- `ip_expense_payments` - платежи по расходам
- `ip_expense_custom` - кастомные поля

### 3. Добавление в меню
Добавьте следующую строку в файл `/application/config/navigation.php`:

```php
'expenses' => [
    'title' => trans('expenses'),
    'class' => 'fa fa-money',
    'href'  => site_url('expenses'),
    'position' => 50
],
```

## Функциональность

### Основные возможности:
1. **Создание расходов** - создание новых расходов с позициями и налогами
2. **Категоризация** - распределение расходов по категориям
3. **Статусы** - управление статусами расходов (новый → подтвержденный → оплаченный)
4. **Налоги** - расчет налогов по позициям и общий налог расхода
5. **Валюты** - поддержка разных валют и курсов обмена
6. **Поиск и фильтрация** - поиск по номерам, категориям, статусам
7. **Отчеты** - суммарные отчеты по периодам и категориям

### Таблицы базы данных:
- **ip_expense_categories** - категории расходов с цветовыми индикаторами
- **ip_expenses** - основная информация о расходах
- **ip_expense_amounts** - итоговые суммы и баланс
- **ip_expense_items** - позиции расходов
- **ip_expense_item_amounts** - расчет сумм для каждой позиции
- **ip_expense_tax_rates** - налоги на весь расход
- **ip_expense_payments** - платежи по расходам
- **ip_expense_custom** - кастомные поля

## Использование

### Создание нового расхода:
1. Перейдите в раздел "Расходы"
2. Нажмите "Создать"
3. Заполните категорию, дату, позиции
4. Добавьте налоги при необходимости
5. Сохраните расход

### Управление статусами:
- **Новый** - создан, но не подтвержден
- **Подтвержденный** - проверен и готов к оплате
- **Оплаченный** - расход оплачен

### Категории расходов:
- Канцелярские товары
- Транспорт
- Питание
- IT и ПО
- Маркетинг и реклама
- Коммунальные услуги
- Командировки
- Образование
- Медицина
- Прочее

## API и AJAX

Модуль поддерживает следующие AJAX операции:
- `expenses/ajax/get_expense_categories` - получение категорий
- `expenses/ajax/get_expense/{id}` - получение данных расхода
- `expenses/ajax/calculate_expense/{id}` - пересчет сумм
- `expenses/ajax/get_expense_statistics` - статистика для дашборда
- `expenses/ajax/search_expenses` - поиск расходов

## Настройки

В файле `sql/create_tables.sql` добавляются следующие настройки:
- `expenses_default_expense_status` - статус по умолчанию для новых расходов
- `expenses_due_after_days` - количество дней до срока оплаты
- `expenses_generate_number_for_new` - автогенерация номера
- `expenses_next_number_prefix` - префикс номера расхода
- `expenses_next_number` - следующий номер
- `expenses_default_currency_code` - валюта по умолчанию
- `expenses_mark_as_paid_on_payment` - автоматическая отметка как оплаченный

## Расширение

Модуль легко расширяется:
1. Добавление новых категорий через базу данных
2. Создание кастомных полей через встроенную систему
3. Добавление новых отчетов и статистики
4. Интеграция с внешними системами через хуки

## Поддержка

Модуль разработан в соответствии со стандартами InvoicePlane и интегрируется с существующими функциями:
- Налоговые ставки
- Валюты и курсы
- Кастомные поля
- Система прав доступа
- Языковые файлы

## Требования

- InvoicePlane 1.0+
- PHP 7.4+
- MySQL 5.7+
- jQuery для AJAX операций

## Лицензия

Модуль распространяется по лицензии InvoicePlane.
